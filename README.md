# 基于 PyTorch 的计算机视觉与 YOLO 目标检测学习项目

---

## Course_Computer_Vision

计算机视觉基础课程代码。

- `Exp/`：课程实验（手部追踪、图像浏览器等）
- `HandLandmarker/`：MediaPipe 关键点检测练习，包括手部检测、姿态估计、瑜伽动作分类

---

## Course_Deep_Learning

深度学习课程代码。

- `Exp/`：期中/期末实验
- `RL_FrozenLake/`：强化学习 FrozenLake 环境实验
- `YOLO26Tracking/`：YOLO 目标追踪专题（追踪、轨迹、变道检测、目标计数）

---

## Course_YOLO

YOLO 目标检测专项课程代码。

- `23_PyTorch_1/`：PyTorch 基础与图像分类
- `YOLO-Classification/`：YOLO 图像分类（数据集处理、训练、验证、预测）
- `YOLO-Detect/`：YOLO 目标检测（数据集划分、训练、推理）
- `YOLO-Pose/`：YOLO 姿态估计（标注、训练、自定义数据集推理）
- `YOLO-PySide6-GUI/`：基于 PySide6 的 YOLO 检测图形界面
