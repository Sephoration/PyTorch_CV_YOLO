# Hand Gesture Recognition Control System

基于 MediaPipe 21 点手部关键点 + KNN / SVM 的实时手势识别控制系统，通过摄像头手势替代键盘/鼠标操作，覆盖 PPT 演示、媒体播放、窗口管理、网页浏览、系统工具、文件操作、文本编辑、应用启动等场景。

---

## 系统架构

```
摄像头采集 ─→ HandTracker (MediaPipe, 320×240 推理)
                  │
                  21 个归一化坐标
                  │
            GestureClassifier (4 种归一化策略 × KNN/SVM = 8 个模型)
                  │
            平滑窗口 (7 帧) + 锁定机制 (0.9s)
                  │
            状态机 (首页 → 功能 → 子手势)
                  │
            Windows API (ctypes, 无 pyautogui)
```

## 模块说明

### p1_extract_features.py — 特征提取

使用 MediaPipe HandLandmarker 从 `train/0` ~ `train/8` 九类手势图片中提取 21 个手部关键点，输出四种归一化特征到 CSV：

| 特征模式 | 维度 | 不变性 |
|----------|------|--------|
| raw | 63 (x,y,z) | 平移 |
| hand | 42 (x,y) | 平移 + 旋转 + 尺度 |
| hand_v2 | 42 (x,y) | 平移 + 旋转 + 尺度（正交基手掌坐标系） |
| dist | 210 | 平移 + 旋转 + 翻转 + 尺度（完全几何不变） |

同时自动进行水平镜像增强，每张原图产生一张镜像图，扩充数据集。

### p2_train_knn.py — 模型训练

对四种特征分别训练 KNN (k=5, weight=distance) 和 SVM (RBF, C=10) 分类器，共输出 8 个 `.pkl` 模型。每个模型都经过 20% 留出测试集评估 + 5 折交叉验证，训练过程中输出详细混淆矩阵和分类报告。

### p3_hand_tracker.py — 手部检测

封装 MediaPipe HandLandmarker，内部将摄像头帧缩放到 320×240 再做推理（速度提升约 10 倍），归一化坐标适配任意显示分辨率绘制骨架。

### p3_gesture_classifier.py — 分类器封装

动态扫描 `models/` 目录加载 `.pkl` 模型，支持运行时热切换。四种归一化方法内联实现，首次预测时自动按文件名推断特征模式。启动时后台预加载所有模型，切换零等待。

### p3_gesture_worker.py — 推理线程

QThread 独立线程运行，核心机制：

- **隔帧检测**：每 3 帧做一次 MediaPipe 检测，大幅降低 CPU 占用
- **预测平滑**：7 帧滑动窗口多数投票，抑制单帧抖动
- **锁定机制**：稳定手势持续 0.9 秒后锁定触发，防止误操作
- **防误断**：连续 3 帧不同手势才解锁，噪声容错
- **死区保持**：手短暂离开画面 0.3 秒内保持锁定进度不丢失
- **冷启动预热**：启动时用空白帧预跑检测器 + 分类器，消除首次卡顿

### p3_gui.py — 图形界面

PySide6 双窗口设计：

- **主窗口**：摄像头画面（含实时骨架绘制）+ 右侧识别面板（锁定进度条、手势数字、置信度、耗时）+ 状态功能卡 + 模型切换 + 显示选项
- **悬浮状态窗**：无边框置顶半透明窗口，始终显示当前状态、当前功能手势列表、锁定进度，不受主窗口遮挡影响

### p3_actions.py — 操作执行

通过 ctypes 直接调用 Windows API 模拟键盘按键，零外部依赖（无 pyautogui）。音量控制优先通过 pycaw 精确调节（每次 6dB），回退到虚拟键码。覆盖 50+ 操作：

| 功能组 | 操作数 | 示例 |
|--------|--------|------|
| PPT 控制 | 8 | 翻页、放映、黑屏、白屏、跳转首末页 |
| 媒体播放 | 6 | 播放暂停、切歌、音量、删除 |
| 窗口管理 | 7 | 最小化最大化、分屏、切换、关闭 |
| 网页浏览 | 6 | 刷新、前进后退、标签页、书签 |
| 系统工具 | 5 | 截图、搜索、运行、设置、任务视图 |
| 文件操作 | 8 | 复制、粘贴、剪切、删除、重命名、新建文件夹 |
| 文本编辑 | 7 | 全选、撤销、重做、保存、查找、替换、打印 |
| 应用启动器 | 6 | 浏览器、记事本、计算器、资源管理器等 |

### p4_main.py — 入口

应用启动入口，配置 Fusion 风格 + Microsoft YaHei 字体。

## 四种特征归一化策略的设计与对比

本系统的核心差异化在于特征工程：对 MediaPipe 输出的 21 个手部关键点原始坐标，设计了四种归一化策略，每种代表一种对「手势不变性」的假设，分别配合 KNN 和 SVM 分类器，共 8 个模型运行时热切换。

### raw — 原始相机坐标（63 维）

将 21 个关键点相对手腕做平移对齐，按手腕到中指根距离归一化尺度。保留完整的 3D 空间信息（x, y, z），对手势在相机视野中的绝对位置不敏感，但对旋转和拍摄角度敏感。

适用场景：摄像头角度固定、用户正对镜头、无需旋转不变性的受控环境。作为基线模型，用于对比其他策略的改进幅度。

### hand — 2D 旋转对齐（42 维）

在 raw 的基础上增加了旋转归一化：计算手腕到中指根的 2D 方向角，将整个手旋转到中指根朝上的标准姿态。丢弃 Z 轴信息，只保留 2D 平面坐标。

设计出发点：大多数手势含义由手指的伸展与弯曲决定，与手在空间中的旋转角度无关。hand 模式在旋转不变性和信息保留之间取得平衡，是本系统的默认推荐模型。缺点是手心/手背翻转时 Z 轴信息丢失可能导致混淆。

### hand_v2 — 手掌正交坐标系（42 维）

不再依赖单一方向向量做旋转对齐，而是用 4 个掌骨点（手腕、食指根、中指根、小指根）构造完整的 2D 正交基：Y 轴为手腕→中指根（手掌纵向），X 轴为食指根→小指根经 Gram-Schmidt 正交化（手掌横向）。所有 21 点投影到该坐标系中，除以 Y 轴长度归一化。

设计出发点：hand 模式的旋转对齐仅依赖于手腕→中指根这条线，当手势导致中指根偏移时（如握拳）对齐质量下降。hand_v2 使用多点的掌骨结构构造坐标系，坐标系本身更稳定，对手势变化更鲁棒。代价是掌骨点检测误差会直接干扰坐标系质量。

### dist — 点对距离特征（210 维）

彻底抛弃坐标对齐思路，改用 21 点两两之间的欧氏距离（共 C(21,2)=210 个距离）作为特征，按手腕→中指根距离归一化。

设计出发点：距离天然具有平移、旋转、翻转不变性——无论手如何翻转、旋转、平移，点对距离不变。这是理论上不变性最强的方案，且镜像增强对其无意义（距离不变）。但代价是丢失了所有空间拓扑信息（如"手指指向哪"），且 210 维特征在高维度下对样本量要求更大。实测中 dist 在 6、7 类等易混淆手势上表现更好，但整体精度受限于训练集大小。

### 对比总结

| 策略 | 维度 | 不变性 | 空间信息 | 典型优势 | 典型劣势 |
|------|------|--------|----------|----------|----------|
| raw | 63 | 平移 | 完整 3D | 信息无损，基线参照 | 对旋转/角度敏感 |
| hand | 42 | 平移+旋转+尺度 | 2D 平面 | 平衡性好，默认推荐 | 手心手背翻转混淆 |
| hand_v2 | 42 | 平移+旋转+尺度 | 2D 平面 | 坐标系更稳定 | 依赖掌骨点检测质量 |
| dist | 210 | 平移+旋转+翻转+尺度 | 无（仅距离） | 理论不变性最强 | 高维，丢失拓扑信息 |

四种策略配合 KNN 和 SVM 两种算法，覆盖了从「保留完整空间信息」到「追求最大不变性」的完整光谱，用户可在 UI 中实时切换对比，选择最适合当前场景的模型组合。

## 项目亮点

**高效的推理管线**：MediaPipe 推理缩放到 320×240（10 倍性能提升），隔帧检测（每三帧一次）、滑动窗口平滑、后台预加载模型预热，冷启动无感。

**工业级防误触设计**：锁定机制要求手势稳定持续 0.9 秒才触发，连续 3 帧不同才解锁，1 秒动作冷却，手短暂离开画面保持进度 0.3 秒——三重容错保证操作可靠。

**零依赖系统操作**：通过 ctypes Windows API 直接模拟键盘，无 pyautogui 等外部依赖，延迟低至毫秒级。音量控制可选 pycaw 精确调节。

**专业的 UI/UX**：主控面板 + 悬浮状态窗双窗口架构，实时骨架绘制 + 锁定进度条动画 + FPS 显示，支持运行中切换模型和显示选项。

## 运行要求

- Python 3.8+

一键安装所有依赖：
```bash
pip install -r requirements.txt
```

或手动安装：
```bash
pip install mediapipe opencv-python PySide6 scikit-learn pandas numpy
```

pycaw 和 comtypes 可选（用于音量精确控制），需要时：
```bash
pip install pycaw comtypes
```

## 使用流程

1. **准备数据**：将手势图片按类别放入 `train/0` ~ `train/8`
2. **提取特征**：`python p1_extract_features.py`
3. **训练模型**：`python p2_train_knn.py`
4. **启动系统**：`python p4_main.py`
