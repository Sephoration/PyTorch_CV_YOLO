## 功能定稿说明

### 1️⃣ PPT 控制
- 上一页/下一页：方向键 ← →
- 开始放映：F5 / 结束放映：Esc
- 黑屏/白屏：演示时按 B/W 遮住画面，再按恢复
- 首页/末页：跳到 PPT 第一页/最后一页

### 2️⃣ 媒体播放
- 支持音乐、视频、图片三种场景
- 上一首/下一首：在图片查看器中相当于上一张/下一张
- 删除：Delete 键，图片查看时可用于删除当前图片
- 音量+ / 音量-：通过 pycaw 或模拟音量键调节

### 3️⃣ 窗口管理
- 最小化 Win+Down / 最大化 Win+Up
- 切换窗口 Alt+Tab / 关闭 Alt+F4
- 分屏左 Win+Left / 分屏右 Win+Right
- 显示桌面 Win+D

### 4️⃣ 网页浏览
- 刷新 F5 / 前进 Alt+Right / 后退 Alt+Left
- 新标签页 Ctrl+T / 关闭标签 Ctrl+W
- 收藏书签 Ctrl+D

### 5️⃣ 系统工具
- 截图 Win+Shift+S / 搜索 Win+S / 运行 Win+R
- 设置 Win+I / 任务视图 Win+Tab

### 6️⃣ 文件操作
- 复制 Ctrl+C / 粘贴 Ctrl+V / 剪切 Ctrl+X
- 删除 Delete / 撤销 Ctrl+Z / 属性 Alt+Enter
- 重命名 F2 / 新建文件夹 Ctrl+Shift+N

### 7️⃣ 文本编辑
- 全选 Ctrl+A / 撤销 Ctrl+Z / 重做 Ctrl+Y
- 保存 Ctrl+S / 查找 Ctrl+F / 替换 Ctrl+H / 打印 Ctrl+P

### 8️⃣ 应用启动器
- 所有操作用 `subprocess.Popen()` 启动系统自带程序
- 浏览器 / 记事本 / 计算器 / 控制面板 / 资源管理器 / 任务管理器

## 安全性说明

所有操作仅使用以下两种安全方式：

| 方式 | 说明 |
|:----|:------|
| **键盘模拟** | `keybd_event()` 模拟按键，等价于手动按键盘 |
| **音量控制** | pycaw（微软官方音频 API）或模拟音量键 |
| **启动程序** | `subprocess.Popen()` 启动系统自带程序 |

**不涉及的操作**（避免使用）：
- 不写注册表（如黑夜模式改为放弃）
- 不调电源 API
- 不操作系统服务
- 不进行提权操作
- 不读写用户文件
- 不做网络/WiFi/蓝牙底层控制
