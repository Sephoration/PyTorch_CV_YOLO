# 计算机视觉期末项目 — 静态手势识别系统使用说明

## 项目概述
基于 **MediaPipe Hands(21点) + KNN/SVM 分类器** 的手势识别系统，
识别数字手势 0-9，提供 PySide6 图形界面演示。

## 项目结构
```
Exp_Final/
├── demo_pyside6.py         # PySide6 演示界面（主程序）
├── extract_features.py     # 数据集→CSV 特征提取
├── train_knn.py             # KNN 训练 + SVM 对比
├── hand_tracker.py          # 手部检测模块（OpenCV 旧版界面用）
├── main.py                  # 多功能手势控制系统（旧版，OpenCV界面）
├── requirements.txt         # 依赖包
├── train/                   # 数据集（0-9，每类124张）
├── csv/
│   └── hand_gesture_data.csv  # 特征数据
├── models/
│   ├── hand_landmarker.task   # MediaPipe 手部检测模型
│   ├── hand_gesture_knn.pkl   # 训练好的 KNN 模型
│   └── hand_gesture_svm.pkl   # 训练好的 SVM 模型
└── images/                   # 图片查看模式资源
```

## 使用步骤

### 1. 激活环境
```bash
conda activate a
```

### 2. 特征提取（可选，已提取完成）
```bash
python extract_features.py
```

### 3. 训练模型（可选，已训练完成）
```bash
python train_knn.py
```

### 4. 启动 PySide6 演示界面
```bash
python demo_pyside6.py
```

### 5. 旧版多模式系统（备选）
```bash
python main.py
```

## 演示界面说明
- **左侧**：摄像头实时画面 + MediaPipe 21点绘制
- **右侧**：
  - 顶部：手势识别结果大图（Emoji + 数字）
  - 中间：各类别置信度条形图
  - 底部：模型切换（KNN / SVM）
- **操作**：点击"开启摄像头"，在手势识别数据集对应的0-9手势前展示即可

## 技术路线
```
原始图片 → MediaPipe Hands 提取21个关键点(x,y,z) → CSV特征数据集
→ KNN/SVM 分类器训练 → 实时摄像头识别(PySide6界面展示)
```
